样式、文本、图片一个不少：外链图自动进入该公众号的素材库再引用，正文 HTML 只做图片地址替换、其余字节零改动。粘贴下面的内容，点一下，草稿就到位。

一键同步
填入服务与文章内容，点击同步。服务地址与卡密保存在本浏览器（localStorage），不上传到任何第三方。
MCP 端点 = 服务地址 + /mcp（如 https://…/wxdraft/mcp）
服务会记住该公众号配置；下次只带 AppID 即可。若换了新 Secret，以本次填写的为准并更新记录。
三种粘贴都支持：① 从 Word / 网页 / AI 对话直接 Ctrl+V，排版自动保留；② 粘贴 HTML 源码（<section>、<img> 等，当 HTML 处理）；③ 纯文本。外链图片自动搬运到素材库并替换地址。

01

卡密鉴权

先鉴权，后执行。支持本地卡密与远程卡密服务，网关层可匿名、安全由卡密承担。

02

图片入素材库

外链 / base64 图片下载后上传到该公众号自己的素材库，换回 media_id 或 CDN 地址。

03

原样替换

只改 <img> 的 src / data-src 属性值，文本、样式、结构其余字节不动。

04

即用即删

过程文件用完立即删除，云函数不留存任何文章与图片；记录只存元数据。

接入你的 AI 客户端
在 Claude / Cursor 等 MCP 客户端中加入以下配置（把地址与卡密换成你的）：
{
  "mcpServers": {
    "gzh-draft": {
      "url": "https://atest-0gvlenb46567649d.service.tcloudbase.com/wxdraft/mcp/"
    }
  }
}

试用无需任何密钥。正式卡密用户请在配置中加一段 "headers": { "X-Card-Key": "你的卡密" }。暴露的工具：sync_draft（同步草稿）、upload_media（素材上传）、list_records / get_record（记录查询）、verify_card_key（卡密校验）。

常见问题
报错了怎么看？

所有错误都返回「人话翻译 + 原始报错」：message 是一句话解释（如“服务器出口 IP 不在公众号 IP 白名单”），raw_error 保留原始 errcode/errmsg 供排查。

公众号 IP 白名单怎么填？

云函数开启了固定公网出口 IP，把它填入公众号后台「设置与开发 → 基本配置 → IP 白名单」即可（当前固定 IP：101.34.223.206）。

一次能同步几篇？有什么限制？

单次 1–8 篇（微信上限）。单图 ≤10MB，格式 png/jpg/jpeg/gif/bmp（webp 微信不支持，会明确报错）。标题 ≤64 字、摘要 ≤120 字。
